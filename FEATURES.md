# ToDWG — возможности (v2.0 beta)

## Запуск и выбор файлов
- Один exe (`ToDWG_v2.0-beta.exe`), работает из любой папки, установка не нужна.
- Выбор `.sdd` кнопкой **или перетаскиванием**; файлы попадают в очередь
  (любой можно убрать крестиком).
- **«Обработать папку…»** — рекурсивный поиск всех `.sdd` в выбранной папке и
  подпапках; найденные файлы **добавляются в список** (без автозапуска) —
  лишние убираются крестиком, затем «Конвертировать». Перед работой папка
  проверяется на доступность с таймаутом.
- Запуск — кнопкой **«Конвертировать»**; она синяя и активна, когда в
  очереди есть файлы.
- Пакетный режим: каждый `.dwg` сохраняется рядом со своим `.sdd`
  (при совпадении имени — `(2)`, `(3)`…).
- Число листов: автоматически или вручную (1–500); при расхождении
  диалога печати и штампов `.sdd` берётся число листов документа.
- Формат листа: **A2** (по умолчанию), **A3**, **A4**; горизонтальный или
  вертикальный — по галочке «Выбрать формат листа вручную (beta)».
- Ручные листы и формат показываются только при включённой в «Настройках»
  опции **«Расширенные настройки главного окна»** (по умолчанию скрыты) и
  доступны **только для одного файла**: при двух и более — блокируются.

## Экспорт из Schemagee
- Schemagee 3.5, штатная процедура «Экспорт в DXF».
- Проверка **каждого листа сразу после экспорта**: файл создан, не пуст,
  читается; до 3 попыток.
- **Самовосстановление**: если Schemagee не отвечает, он закрывается и
  открывается заново, лист повторяется (до 3 перезапусков на файл).
- **Устойчивый первый запуск**: клавиши отправляются по виртуальным кодам
  (не зависят от раскладки); при неудаче определения числа листов Schemagee
  перезапускается и файл открывается заново.
- Экстренная остановка **Ctrl+Alt+0** в любой момент; подсказка на экране.
- Запуск блокируется, если Schemagee уже открыт.

## Сборка альбома
- Схемы в пространстве модели в ряд; шаг — по реальному размеру листа.
- Отдельный layout на каждый лист выбранного формата (A2/A3/A4).
- Шрифт ISOCPEUR Italic (`isocpeui.ttf`) для всех стилей.
- Автокоррекция размера текста (сжатие 0.5–0.6).
- DXF читаются в cp1251/ANSI и UTF-8; битые файлы Schemagee починяются автоматически.

## Конвертация и результат
- DXF → DWG через AutoCAD или ODA File Converter; без конвертера остаётся DXF.
- **Удаление `.dxf` после конвертации** (галочка, включена по умолчанию).
- Результат: по умолчанию каждый `.dwg` — **рядом со своим `.sdd`**; строка
  «Сохранить в:» показывает «Рядом с исходным файлом» (неактивно). Галочка
  **«Выбрать папку для готовых файлов»** активирует строку, кнопка
  «Изменить…» открывает выбор папки (старт — из папки первого исходного
  файла); выбранная общая папка действует до конца сеанса. Сетевые (UNC)
  папки разрешены, но проверяются на доступность/чтение/запись в фоновом
  потоке с таймаутом (5 с); при недоступности — понятное сообщение.
- `placed.json`, `result.json`, `ToDWG.log` — служебные; по умолчанию **не
  ведутся** (галочка «Сохранять журнал конвертирования»); при включении
  пишутся в папку настроек `Документы\ToDWG` и перезаписываются при каждом
  запуске (без накопления).

## Интерфейс и отчёты
- Окна: прогресс, успех, ошибка, «Остановлено», сводный отчёт по пакету.
- **Отчёт о конвертации по завершении** (галочка, включена по умолчанию).
- Кнопка **«Настройки»**: окно модальное (главное окно недоступно), конфиг
  пишется только по кнопке «Сохранить и закрыть» (крестик — отмена); скорость
  кликера (4 шага, по умолчанию «Оптимально»), «Задержки кликера (для
  медленных ПК)» (вкл.; без них полоса скорости неактивна, движок скрыт,
  показана подсказка),
  журнал (выкл.), удаление DXF (вкл.), отчёт (вкл.); у каждой галочки — «?»
  (краткая справка); конфиг — `Документы\ToDWG\ToDWG_settings.json`.
- **Скорость кликера** запоминается; «Медленно» на 15% медленнее прежнего,
  «Очень быстро» — заметно быстрее. Без задержек — паузы ×0.1 и опрос
  состояния. При ошибке после 3 попыток скорость снижается на шаг с повтором
  листа, после 3 снижений подряд фиксируется ниже.
- Отчёт: компактное «Готово» и пакетный отчёт с деталями по файлам; кнопки
  «Открыть папку», «Закрыть отчет» (в главное окно), «Завершить работу».
- **Блокировка нажатий мыши** на время конвертации (курсор двигается свободно,
  клавиатура активна; Ctrl+Alt+0 снимает блокировку и останавливает работу).
- Единая область перетаскивания/списка: без файлов — подсказка, с файлами
  — список с прокруткой колесом и крестиками удаления.
- **Тёмная тема по умолчанию** (мягкая, неконтрастная); переключатель на
  главном экране переводит в светлую.
- Лог с ротацией (2 МБ).
- Русский интерфейс; рекламы, баннеров и донатов нет.

## Служебное
- Ключи для отладки: `--dxf-folder`, `--name`, `--headless`, `--out-dir`.
- Тесты: остановка, экспорт, диалоги, ремонт DXF, кодировка, GUI, собранный exe.
