# ToDWG v2.0 (beta) — Schemagee → DXF → DWG

Автоматизирует штатный экспорт листов из Schemagee 3.5 (`.sdd`) в DXF и
собирает из них один альбом DWG: схемы в пространстве модели в ряд и по
отдельному layout на каждый лист (A2).

Всё в одном файле `ToDWG_v2.py`; exe не зависит от места запуска и
соседних файлов. **По умолчанию каждый `.dwg` сохраняется рядом со своим
исходным `.sdd`**; можно включить «Выбрать папку для готовых файлов» и
указать общую папку. Журнал (при включённой галочке «Сохранять журнал
конвертирования») — в папке настроек `Документы\ToDWG`.

Возможности: [FEATURES.md](FEATURES.md) · Изменения: [CHANGELOG.md](CHANGELOG.md) ·
Планы: [ROADMAP.md](ROADMAP.md)

## Структура проекта

```
ToDWG\
├─ ToDWG_v2.py              основной скрипт (кликер + конвертер + GUI)
├─ ToDWG_v2.spec            сборка PyInstaller (onefile, без консоли)
├─ Logo_toDWG.ico           иконка, вшивается в exe
├─ README.md                краткое описание и запуск
├─ FEATURES.md              список всех возможностей
├─ CHANGELOG.md             история изменений по версиям
├─ ROADMAP.md               планы и идеи
├─ input\                   26 DXF (результат экспорта) — данные для тестов
├─ dist\                    собранный ToDWG_v2.0-beta.exe (локально, не в git)
└─ tests\                   локальные проверки (не входят в exe)
```

Не публикуются в репозитории (в `.gitignore`): `Примеры\` с исходными
`.sdd`, `ToDWG (исходники)\`, `archive\` и `docs\` с отчётами и планом.

## Запуск из исходников

```powershell
python ToDWG_v2.py                 # GUI
python ToDWG_v2.py --headless --dxf-folder input --name check
```

Ключи (только для отладки):

| Ключ | Назначение |
|---|---|
| `--dxf-folder ПАПКА` | пропустить кликер, собрать альбом из готовых DXF |
| `--name ИМЯ` | имя итогового файла без расширения |
| `--headless` | без окон: выполнить и напечатать отчёт |
| `--out-dir ПАПКА` | папка для результатов (по умолчанию — рядом с программой) |

Рабочий цикл GUI: **«Добавить файлы»** (или перетащить `.sdd`) → файлы
попадают в список (лишние убираются крестиком) → **«Конвертировать»**.
Программа сама открывает Schemagee, экспортирует каждый лист (с проверкой
после каждого), собирает DWG и показывает отчёт.
**По умолчанию каждый `.dwg` сохраняется рядом со своим исходным `.sdd`**
(при совпадении имени — суффикс `(2)`, `(3)`…), поэтому строка
«Сохранить в:» показывает «Рядом с исходным файлом».
**«Обработать папку…»** рекурсивно находит все `.sdd` в выбранной папке и
подпапках и **добавляет их в список** (без автозапуска) — уберите лишние и
нажмите «Конвертировать». Перед работой папка проверяется на доступность
(в т. ч. сетевая — с таймаутом).
Чтобы сохранять все результаты в одну папку, включите **«Выбрать папку для
готовых файлов»** и нажмите «Изменить…» (диалог стартует из папки первого
исходного файла).
Ручное число листов и формат доступны только при включённой в «Настройках»
опции «Расширенные настройки главного окна» и только для **одного** файла.
В окне отчёта: «Открыть папку», «Закрыть отчет», «Завершить работу».

Настройки (кнопка **«Настройки»** в главном окне): окно модальное — пока оно
открыто, главное окно недоступно; изменения применяются по кнопке
**«Сохранить и закрыть»**, крестик закрывает без сохранения.
- **Скорость кликера** (ползунок): Оптимально (по умолчанию), Медленно
  (на 15% медленнее), Быстро, Очень быстро; запоминается;
- **Задержки кликера (для медленных ПК)** (включены): снять — паузы ×0.1 и
  работа по опросу состояния (быстрее; при промахе — повторы), при этом полоса
  скорости остаётся видимой, но неактивной, движок скрыт, а ниже — подсказка
  «Настройка невозможна: задержки выключены — скорость максимальная»;
- **Сохранять журнал конвертирования** (по умолчанию выключена) — в папке
  настроек `Документы\ToDWG` ведутся `ToDWG.log`, `result.json`,
  `placed.json`; файлы перезаписываются при каждом запуске (без накопления),
  папка с `.dwg` не захламляется;
- **Удалять .dxf файлы после конвертации** (включена) — в папке остаётся
  только итоговый `.dwg`;
- **Выводить отчёт по завершении** (включена) — для нескольких файлов
  показывается сводный отчёт;
- **Блокировать нажатия мыши во время конвертации** (включена) — нажатия
  кнопок не действуют, курсор двигается свободно, клавиатура остаётся;
  аварийный останов **Ctrl+Alt+0** снимает блокировку и останавливает работу.
- **Расширенные настройки главного окна** (выключена) — показывать на главном
  экране ручное число листов и выбор формата; значение хранится в конфиге.

Конфигурация хранится в `Документы\ToDWG\ToDWG_settings.json` (папка
«Мои документы», права администратора не нужны): тема, скорость/задержки
кликера, галочки журнала/удаления DXF/отчёта/блокировки мыши и
«Расширенные настройки главного окна». Папка результата и ручное число
листов не сохраняются.

Экстренная остановка — **Ctrl+Alt+0** (работает всегда, даже во время
экспорта; подсказка выведена на главном экране под кнопкой).

## Сборка exe

```powershell
python -m PyInstaller ToDWG_v2.spec --clean --noconfirm
```

Результат: `dist\ToDWG_v2.0-beta.exe` (onefile, ~30 МБ). Папка `build\`
пересоздаётся и в репозиторий не входит.

## Тесты

```powershell
python tests\_test_stop.py         # экстренная остановка, паузы, хоткей
python tests\_test_export.py       # нажатие кнопки «Экспорт» в форме Schemagee
python tests\_test_dxf_repair.py   # починка битых DXF + чтение input\*.dxf
python tests\_gui_selftest.py      # сборка главного окна без mainloop
python tests\_test_dialog.py       # подтверждение диалога #32770
python tests\_test_dialog2.py      # WM_COMMAND(IDOK) для MB_OKCANCEL
python tests\_test_exe_gui.py      # собранный exe: окно открывается/закрывается
python tests\_check_dwg.py "альбом.dwg"  # проверка DWG через AutoCAD
python tests\_live_run.py "путь\file.sdd" [--sheets N]  # живой прогон
```

Тесты создают временные диалоги и окна, поэтому запускать их нужно на
машине с рабочим столом (не в headless-сессии Windows).

## Требования

- Python 3.14 (проверено), пакеты: `ezdxf`, `pywin32`, `keyboard`,
  `pyperclip`, `tkinterdnd2`, `pyinstaller`;
- Schemagee 3.5 (лицензия Организации);
- для DWG: AutoCAD (COM) или ODA File Converter. Если нет ни того, ни
  другого — остаётся собранный DXF, об этом пишется в отчёт;
- шрифт `isocpeui.ttf` (ISOCPEUR Italic) — должен быть установлен в
  Windows.

## Известные ограничения

- Кликер управляет Schemagee имитацией клавиш: во время работы нельзя
  трогать мышь и клавиатуру;
- Schemagee должен быть закрыт перед запуском: если он открыт, программа
  спрашивает, закрыть его и продолжить (с предупреждением о несохранённых
  изменениях) или вернуться в главное окно, не трогая открытый документ;
- PDF не создаётся;
- по умолчанию каждый `.dwg` пишется рядом со своим исходным `.sdd`; чтобы
  сохранять в общую папку, включите «Выбрать папку для готовых файлов» →
  «Изменить…» (выбор действует до конца сеанса, в конфиг не пишется);
  сетевые папки разрешены, но проверяются на доступность с таймаутом;
- по умолчанию рядом с `.dwg` остаётся только итоговый файл; служебные
  `placed.json`, `result.json`, `ToDWG.log` ведутся лишь при включённой
  галочке «Сохранять журнал конвертирования» и лежат в папке настроек
  `Документы\ToDWG` (перезаписываются, а не накапливаются).

Отчёты и список задач ведутся локально в папке `docs\` и в репозиторий
не выкладываются.
